One sentence pitching a ridiculous invention that fixes a tiny everyday annoyance, for the [One-Sentence Absurd Invention Pitch](https://make.fun/bounty/u-suroso-69-one-sentence-absurd-invention-pitch-5326c34a) bounty on make.fun.

## The pitch (169 characters)

> Introducing the Apology Alarm Clock, a bedside clock that wakes you up, then spends ten minutes sincerely apologising for existing, so you feel too guilty to hit snooze.

## How it works

`main.ts` writes the pitch to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`) and validates it first: 1–220 characters, a single line, no surrounding whitespace, and a single complete sentence.

Run it with:

```sh
node main.ts
```
